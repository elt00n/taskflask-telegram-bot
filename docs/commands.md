# Команды Telegram Task Bot

## Быстрое создание задачи

Минимальная команда содержит только название:

```text
/task Купить молоко
```

Такая задача создаётся без времени и попадает во «Входящие».

## Время начала

Поддерживаются шаблоны:

```text
/task сегодня 18:00 Позвонить врачу
/task сегодня в 18:00 Позвонить врачу
/task завтра 10:00 Позвонить врачу
/task завтра в 10:00 Позвонить врачу
/task в пятницу 19:00 Ужин
```

Для дня недели выбирается ближайшее будущее наступление указанного времени. Если
время окончания не указано, событие по умолчанию длится один час.

## Дедлайн

Дедлайн по календарной дате:

```text
/task до 25 августа Подготовить презентацию
/task до 25 августа 18:00 Подготовить презентацию
/task до 25 августа 2027 18:00 Подготовить презентацию
```

Дедлайн по дню недели:

```text
/task до пятницы Закончить макет
/task до пятницы 18:00 Закончить макет
```

Если время дедлайна не указано, используется `23:59`. Если год не указан и дата в
текущем году уже прошла, выбирается следующий год. Явно указанная прошедшая дата
считается ошибкой.

## Важность

Слова-маркеры можно добавить в команду:

```text
/task Подготовить презентацию важно
/task Исправить production срочно
```

- `важно` — высокая важность;
- `срочно` — критическая важность;
- без маркера — обычная важность.

Маркер удаляется из названия задачи. Если одновременно указаны оба маркера,
используется критическая важность.

## Участники

Участники указываются через Telegram username:

```text
/task в пятницу 19:00 Ужин @anna @ivan
```

Повторные упоминания удаляются без изменения порядка. Usernames нормализуются в
нижний регистр и не входят в название. После подключения Telegram transport будет
сопоставлять их с известными боту участниками текущего чата.

## Комбинированный пример

```text
/task до пятницы 18:00 Закончить макет @anna срочно
```

Результат разбора:

```text
Название: Закончить макет
Дедлайн: ближайшая пятница, 18:00
Участники: anna
Важность: критическая
```

## Ограничения первой версии

Парсер намеренно распознаёт только однозначные шаблоны. Пока не поддерживаются:

- произвольный порядок даты и названия;
- продолжительность вроде `на 45 минут`;
- повторения вроде `каждый понедельник`;
- свободные фразы вроде `вечером` или `после обеда`;
- поиск пользователя по отображаемому имени вместо username.

Эти возможности будут добавляться отдельными правилами и тестами, чтобы бот не
угадывал дату неправильно.
